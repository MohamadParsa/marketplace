# فهرست استان‌ها و شهرهای ایران

بسته آماده ورود شامل **۳۱ استان و ۱۴۸۱ شهر** است؛ ورود دستی فهرست کشور لازم نیست. این بسته در ۲۰۲۶-۱۱-۲۷ از نسخهٔ ثابت `3.1.2` [منبع عمومی list-of-cities-in-Iran](https://github.com/sajaddp/list-of-cities-in-Iran/tree/ace21bb251f96ced350bbc01541acffd71121feb) دریافت شده است. بنا بر شرح و manifest منبع، مبنای آن فایل تقسیمات کشوری پایان **۱۴۰۴** است. مخزن واسط دولتی نیست و این نسخه ادعای پوشش تغییرات پس از آن سال ندارد.

## محتوا و مجوز

- [فهرست قابل ورود](iran-provinces-cities.json): مدل استان/شهر سیستم با شناسهٔ پایدار برگرفته از کد منبع.
- [منشأ، checksumها و رفع ابهام نام‌ها](provenance.json).
- `upstream/`: فایل‌های خام استان، شهر پالایش‌شده، شهرستان و manifest، همراه [متن مجوز GPL-3.0 منبع](upstream/license.txt). این مجوز مربوط به دادهٔ دریافت‌شده است؛ مجوز سایر بخش‌های پروژه با این سند تعیین نمی‌شود.
- `cities-filtered` فقط شهرها را دارد؛ ۱۹۱ منطقهٔ شماره‌دار شهریِ موجود در خروجی جامع منبع، شهر مستقل وارد نشده‌اند. روستا، بخش و شهرستان نیز به فهرست شهر اضافه نمی‌شوند.

برای نام‌های تکراری در یک استان، نام شهرستان داخل پرانتز آمده است: دو گلوگاه در مازندران و دو کشکوییه و دو علی‌آباد در کرمان. حروف فارسی و فاصله‌های نمایشی در فایل نهایی یکسان شده‌اند؛ فایل خام حفظ شده است.

## بازتولید و ورود

از ریشهٔ مخزن:

```powershell
node scripts/geography/build-iran-geography.cjs
Set-Location apps/api
go run ./cmd/geography-import -file ../../data/iran-geography/iran-provinces-cities.json -validate-only
```

ابزار به اینترنتِ زمان اجرا وابسته نیست. برای ورود به دیتابیس بررسیِ از قبل راه‌اندازی‌شده، متغیر `REVIEW_DATABASE_URL` را در محیط خصوصی همان ترمینال تنظیم کنید؛ `DATABASE_URL` نباید هم‌زمان تنظیم باشد. ابتدا پیش‌نمایش:

```powershell
go run ./cmd/geography-import -file ../../data/iran-geography/iran-provinces-cities.json -mode review
```

پس از بررسی تعدادها، مسیر مطلق یک فایل پشتیبان **جدید** را بدهید؛ پوشهٔ آن از قبل موجود باشد. مثال مسیر خصوصی ویندوز:

```powershell
$taskBackup = Join-Path $env:TEMP ("cherriva-geography-before-" + [guid]::NewGuid().ToString("N") + ".json")
go run ./cmd/geography-import -file ../../data/iran-geography/iran-provinces-cities.json -mode review -apply -backup $taskBackup
```

برای محیط عملیاتی، همین ابزار با `-mode live` و فقط `DATABASE_URL` خصوصی اجرا می‌شود؛ این تحویل روی سرور اجرا نشده است. تطبیق `data_origin` اجباری است. ابزار migration یا ایجاد workspace روی دیتابیس خالی انجام نمی‌دهد. اطلاعات اتصال را در Git، مستندات یا خروجی اشتراکی ثبت نکنید.

ادغام افزایشی است: استان/شهر موجود با نام یکسان، حتی با تفاوت نگارشی متعارف، همان شناسه و وضعیت قبلی را نگه می‌دارد. مقصد غیرفعال دوباره فعال نمی‌شود؛ رکورد سفارشی حذف نمی‌شود. برخورد شناسه، نام مبهم و جابه‌جایی شهر میان استان‌ها رد می‌شود. تغییر هم‌زمان نسخهٔ تنظیمات، اجرا را با conflict متوقف می‌کند؛ پیش‌نمایش را دوباره بگیرید.

پشتیبان فقط فهرست جغرافیا و نسخهٔ قبلی تنظیمات را دارد. اعمال در یک تراکنش، همراه یک audit انجام می‌شود؛ اجرای مجددِ بدون تغییر، نسخه و audit تازه نمی‌سازد. برگرداندن کورکورانهٔ پشتیبان مجاز نیست: ابتدا ارجاع‌های جدیدِ آدرس و پوشش حمل بررسی شوند، چون حذف مقصد دارای سابقه خلاف قرارداد سیستم است.

ویرایش و غیرفعال‌سازی بعدی از «تنظیمات خرید و حمل ← استان‌ها و شهرها» با مجوز موجود `geography.write` ممکن است. واردشدن شهر، پوشش ارسال فروشگاه را خودکار گسترش نمی‌دهد؛ قواعد روش حمل همچنان اعمال می‌شوند. بروزرسانی اینترنتی خودکار فعال نشده است؛ نسخهٔ بعدی باید جدا دریافت، بررسی و ادغام شود.
