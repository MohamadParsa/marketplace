# طراحی بک‌آفیس و پنل مشترک چریوا

شناسه: CVBO-PACK-01 | نسخه: ۰.۲ | تاریخ: ۲۰۲۶-۱۱-۱۷ | وضعیت: پیشنهاد طراحی، در انتظار بازبینی | مالک تصمیم: الیاس؛ بازبینان پیشنهادی: محصول و راهبر فنی

این بسته، طراحی مستقل از محصول است: ورود و داشبورد از ساختار سورس فعلی ایده می‌گیرند و امکانات تحلیل جدید به پنل اضافه شده‌اند. برای ساخت این بسته هیچ فایل محصول در `D:\Cherriva` تغییر نکرده است. تکمیل نمونه تعاملی، به معنای پیاده‌سازی یا تأیید نهایی قواعد تجاری نیست.

## دیدن طرح

فایل [index.html](index.html) را در مرورگر باز کنید؛ فایل‌ها و فونت‌ها محلی‌اند. اگر مرورگر اجرای فایل محلی را محدود کرد، در همین پوشه `node serve.cjs` را اجرا و [پیش‌نمایش محلی](http://127.0.0.1:4179/) را باز کنید. سرور اختیاری فقط روی loopback است و به نصب بسته نیاز ندارد. بستن فرایند با Ctrl+C.

- ورود نمونه: همه نماهای دسترسی با همان هویت `USR-001` و موبایل `09000000001`؛ کد ثابت **000000**؛ هیچ پیامکی ارسال نمی‌شود.
- نوار بالایی ابزار **بررسی طراحی** است: سه جهت A/B/C، پنج نمای دسترسی از همان هویت و حالت‌های خالی/بارگذاری/خطا/عدم دسترسی. این نوار در محصول نهایی وجود ندارد.
- ورود مستقیم به صفحه‌ها و تغییر نقش برای تسهیل بازبینی مجاز است؛ این رفتار احراز هویت یا امنیت محصول نیست.
- A متعادل و شیک، B فروش‌محور و متراکم‌تر، C لوکس با زمینه گرم‌تر. ساختار و قواعد یکسان‌اند. پیشنهاد طراح برای شروع پنل **A** است؛ انتخاب نهایی ثبت نشده است.
- داده‌ها ساختگی و مبالغ نمایشی **تومان** هستند. قرارداد تحلیل برای پیاده‌سازی: مبلغ صحیح **ریال** در سرور/API، نمایش تومان؛ محاسبه JavaScript این نمونه موتور مالی نیست.

## پنج مسیر پیشنهادی برای جلسه بازبینی

1. ورود مدیر → داشبورد → سفارش خرید چندفروشنده‌ای → جزئیات تأمین.
2. حساب سلر → عرضه‌های خود → سفارش پیش از تأمین → تأیید نمونه → مرسوله.
3. روش فروش → محاسبه ۱۰۰۰ منهای ۱۰۰ → مارکاپ ۴٪ → ارسال ۵۰ → **۹۸۶**؛ سپس اقساطی/پارسیان با صفر صریح.
4. سکشن‌ها → ویترین gold → ترتیب/نمایش → پیش‌نمایش → انتشار شبیه‌سازی‌شده.
5. مالی → تراکنش نامشخص → استعلام نمایشی → باقی‌ماندن در «در حال بررسی».
