# BO-13 — مارکاپ دسته‌بندی

شناسه سند: CVBO-BO-13 | نسخه: ۰.۱ | تاریخ: ۲۰۲۶-۱۱-۱۷ | وضعیت: in-review | مالک تصمیم: الیاس؛ بازبین فنی پیشنهادی: راهبر فنی، انتساب شخص باز

## هدف بیزینسی

نزدیک‌ترین قانون دسته، جایگزین درصد پیش‌فرض روش فروش. این فرم باید اقدام بعدی و محدوده مسئولیت را روشن کند؛ ظاهر فرم جای تصمیم باز یا اجازه اجرای عملیات نیست.

## داده و فیلدهای تحلیل

دسته، روش، درصد شامل صفر، نسخه

## مسیر اصلی

انتخاب دسته و روش → درصد شامل صفر → preview زنجیره دسته → نزدیک‌ترین قانون، وگرنه پیش‌فرض. درصدها جایگزین‌اند و جمع نمی‌شوند.

## دسترسی

عملیات پیشنهادی رجیستری: markups.view/edit

نمای نقش‌های نمونه: مدیر کل، مالی. نقش‌های نمونه تعیین نهایی اختیار نیستند. هر عملیات سمت سرور مجوز مستقل می‌خواهد؛ سلر فقط فروشگاه منتسب، نه scope ارسالی دلخواه کلاینت.

## اعتبارسنجی و حالات

preview مسیر انتخاب؛ نزدیک‌ترین دسته؛ عدم جمع

loading، empty، error و forbidden از نوار بررسی قابل مشاهده‌اند. جست‌وجو و وضعیت روی فهرست‌های جدول‌دار فعال‌اند. در محصول خطای اعتبارسنجی، conflict و retry امن به فرم متصل شوند؛ این نمونه همه قراردادهای backend را اجرا نمی‌کند.

## پذیرش پیشنهادی تیم

- مسیر اصلی بالا با داده آزمون و نقش مجاز قابل تکمیل باشد؛ داده یا عملیات خارج scope نمایش و اجرا نشود.
- قواعد و محدودیت‌های همین صفحه و [مرجع تحلیل](../references/backoffice-analysis-fa.md) در API و UI یکسان باشند.
- خطا و داده خالی قابل فهم باشند؛ متن طولانی، رقم فارسی و نمای موبایل آزمون شوند.
