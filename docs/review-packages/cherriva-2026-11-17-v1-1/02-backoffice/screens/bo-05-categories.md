# BO-05 — دسته‌بندی‌ها

شناسه سند: CVBO-BO-05 | نسخه: ۰.۲ | تاریخ: ۲۰۲۶-۱۱-۱۷ | وضعیت: in-review | مالک تصمیم: الیاس؛ بازبین فنی پیشنهادی: راهبر فنی، انتساب شخص باز

## هدف بیزینسی

یک ساختار درختی برای تمام ویترین‌های چریوا. این فرم باید اقدام بعدی و محدوده مسئولیت را روشن کند؛ ظاهر فرم جای تصمیم باز یا اجازه اجرای عملیات نیست.

## داده و فیلدهای تحلیل

والد، عنوان، slug، ترتیب، SEO، خصوصیات و سه ویژگی کارت

## مسیر اصلی

انتخاب گره درخت → والد/slug/ویترین → متن PLP و خصوصیات کارت → اعتبارسنجی چرخه در محصول. انتقال دسته فعال تا تعیین CHQ-09 اجرا نشود.

## دسترسی

عملیات پیشنهادی رجیستری: categories.view/edit/archive

نمای نقش‌های نمونه: مدیر کل، فقط مشاهده. نقش‌های نمونه تعیین نهایی اختیار نیستند. هر عملیات سمت سرور مجوز مستقل می‌خواهد؛ سلر فقط فروشگاه منتسب، نه scope ارسالی دلخواه کلاینت.

## اعتبارسنجی و حالات

منع چرخه؛ استفاده فعال و جابه‌جایی CHQ-09

loading، empty، error و forbidden از نوار بررسی قابل مشاهده‌اند. جست‌وجو و وضعیت روی فهرست‌های جدول‌دار فعال‌اند. در محصول خطای اعتبارسنجی، conflict و retry امن به فرم متصل شوند؛ این نمونه همه قراردادهای backend را اجرا نمی‌کند.

## پذیرش پیشنهادی تیم

- مسیر اصلی بالا با داده آزمون و نقش مجاز قابل تکمیل باشد؛ داده یا عملیات خارج scope نمایش و اجرا نشود.
- قواعد و محدودیت‌های همین صفحه و [مرجع تحلیل](../references/backoffice-analysis-fa.md) در API و UI یکسان باشند.
- خطا و داده خالی قابل فهم باشند؛ متن طولانی، رقم فارسی و نمای موبایل آزمون شوند.
