# BO-21 — تأمین جایگزین

شناسه سند: CVBO-BO-21 | نسخه: ۰.۱ | تاریخ: ۲۰۲۶-۱۱-۱۷ | وضعیت: in-review | مالک تصمیم: الیاس؛ بازبین فنی پیشنهادی: راهبر فنی، انتساب شخص باز

## هدف بیزینسی

واگذاری مقدار مشخص، با حفظ مبلغ پرداختی مشتری. این فرم باید اقدام بعدی و محدوده مسئولیت را روشن کند؛ ظاهر فرم جای تصمیم باز یا اجازه اجرای عملیات نیست.

## داده و فیلدهای تحلیل

قلم/تعداد، تأمین‌کننده جایگزین، قرارداد snapshot، آماده‌سازی

## مسیر اصلی

پرونده کسری → مقدار واگذاری → تأمین‌کننده جایگزین → قرارداد snapshot → تأیید → ارسال. مبلغ مشتری ثابت می‌ماند.

## دسترسی

عملیات پیشنهادی رجیستری: assignments.view/create/confirm

نمای نقش‌های نمونه: مدیر کل، فروشنده، پشتیبانی. نقش‌های نمونه تعیین نهایی اختیار نیستند. هر عملیات سمت سرور مجوز مستقل می‌خواهد؛ سلر فقط فروشگاه منتسب، نه scope ارسالی دلخواه کلاینت.

## اعتبارسنجی و حالات

فقط اقلام واگذارشده؛ مبلغ مشتری ثابت

loading، empty، error و forbidden از نوار بررسی قابل مشاهده‌اند. جست‌وجو و وضعیت روی فهرست‌های جدول‌دار فعال‌اند. در محصول خطای اعتبارسنجی، conflict و retry امن به فرم متصل شوند؛ این نمونه همه قراردادهای backend را اجرا نمی‌کند.

## پذیرش پیشنهادی تیم

- مسیر اصلی بالا با داده آزمون و نقش مجاز قابل تکمیل باشد؛ داده یا عملیات خارج scope نمایش و اجرا نشود.
- قواعد و محدودیت‌های همین صفحه و [مرجع تحلیل](../references/backoffice-analysis-fa.md) در API و UI یکسان باشند.
- خطا و داده خالی قابل فهم باشند؛ متن طولانی، رقم فارسی و نمای موبایل آزمون شوند.
