# CV-DSC-01 — مدل تخفیف محصول و منبع هزینه

وضعیت تحلیل: بخش وابسته مسدود / بخش مستقل قابل شروع. مبنای بیزینسی از [تصمیم‌ها](../01-scope-decisions.md)؛ مسیر فنی پیشنهاد این بسته است. مسئول پیشنهادی: backend + frontend پنل + مالی؛ انتساب فرد/موعد انجام نشده است.

## هدف بیزینسی

تخفیف واقعی کالا و هزینه چریوا/سلر جدا و قابل گزارش باشند.

## دامنه و راه‌حل فنی

Promotion typed fixed/percent/cap/dates/target/method/funder؛ eligibility و version مستقل از UI. درصد/مبلغ منفی رد؛ composite funding بدون تصمیم فعال نشود.

محل تجربه: **BO-15**. مرجع طراحی: [06-catalog-pricing.md](../06-catalog-pricing.md)؛ قرارداد عملیات و خطا: [API](../04-api-contracts.md). فقط منابع و عملیات همین تسک در دامنه تغییرند؛ قابلیت جدید نامرتبط یا پاسخ CHQ به‌صورت حدسی اضافه نشود.

## ترتیب انجام و خروجی

1. وابستگی‌های زیر و سؤال‌های همین مسیر را کنترل؛ DTO/ورودی/خروجی، permission و شرط وضعیت مرتبط را از قرارداد استخراج کنید.
2. use case/adapter یا component محدود طبق راه‌حل بالا بسازید؛ تغییر داده با نسخه و عملیات تکرارشونده با کلید یکتا کنترل شوند. برای task رابط کم‌خطر کنترل‌های نامرتبط مالی اضافه نکنید.
3. معیارهای زیر را با داده ساختگی بررسی و خروجی قابل بازبینی شامل کد/قرارداد لازم، تست متناسب و گزارش تحویل بدهید. schema یا API جدید باید با مصرف‌کننده هماهنگ باشد.

## معیار پذیرش

- CV-DSC-01-AC01: یک تخفیف چریوا و یک تخفیف سلر جدا ثبت شوند.
- CV-DSC-01-AC02: تخفیف منقضی یا برای روش نامرتبط از قیمت کسر نشود.

## مجوز، خطا و بررسی

قواعد نقش/فرم/عملیات سند پنل و scoped DTO سند معماری در تمام دسترسی‌های مرتبط اعمال شوند. بررسی معنادار این گروه: **انقضا، شرط نامنطبق، مصرف هم‌زمان، سهم funder و لغو جزئی**. برای عملیات سرور، پذیرش‌های مثبت/منفی مرتبط با DB/adapter آزمون بررسی شوند؛ برای ظاهر، مرور بصری و تعاملی متناسب کافی است و تست تقلیدی لازم نیست. نوع و نتیجه هر بررسی در گزارش ثبت شود؛ این فایل خود گزارش آزمون نیست.

شناسه تسک، فایل‌های تغییرکرده، رفتار حاصل، نتیجه بررسی‌ها با شاهد، قرارداد مؤثر و مانع باقی‌مانده؛ طبق [فرمت تحویل](../16-agent-delivery.md). همه تسک‌ها در این نسخه todo هستند؛ تهیه سند به معنی شروع یا اتمام کدنویسی نیست.
