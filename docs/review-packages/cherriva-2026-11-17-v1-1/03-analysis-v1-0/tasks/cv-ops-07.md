# CV-OPS-07 — مرسوله، بسته‌ها و اعزام

وضعیت تحلیل: دامنه پایه روشن؛ اجرای پس از وابستگی‌ها. مبنای بیزینسی از [تصمیم‌ها](../01-scope-decisions.md)؛ مسیر فنی پیشنهاد این بسته است. مسئول پیشنهادی: backend سفارش + frontend پنل + عملیات؛ انتساب فرد/موعد انجام نشده است.

## هدف بیزینسی

همه اقلام باقی‌مانده سلر یکجا اعزام و چند بسته رهگیری شوند.

## دامنه و راه‌حل فنی

shipment/packages/tracking با اقلام و version؛ guard آماده‌بودن/تأمین؛ dispatch بسته‌ها هم‌زمان. race لغو/اعزام transactional؛ ثبت کد/زمان/عامل.

محل تجربه: **BO-19**. مرجع طراحی: [09-order-shipping.md](../09-order-shipping.md)؛ قرارداد عملیات و خطا: [API](../04-api-contracts.md). فقط منابع و عملیات همین تسک در دامنه تغییرند؛ قابلیت جدید نامرتبط یا پاسخ CHQ به‌صورت حدسی اضافه نشود.

## ترتیب انجام و خروجی

1. وابستگی‌های زیر و سؤال‌های همین مسیر را کنترل؛ DTO/ورودی/خروجی، permission و شرط وضعیت مرتبط را از قرارداد استخراج کنید.
2. use case/adapter یا component محدود طبق راه‌حل بالا بسازید؛ تغییر داده با نسخه و عملیات تکرارشونده با کلید یکتا کنترل شوند. برای task رابط کم‌خطر کنترل‌های نامرتبط مالی اضافه نکنید.
3. معیارهای زیر را با داده ساختگی بررسی و خروجی قابل بازبینی شامل کد/قرارداد لازم، تست متناسب و گزارش تحویل بدهید. schema یا API جدید باید با مصرف‌کننده هماهنگ باشد.

## معیار پذیرش

- CV-OPS-07-AC01: چند بسته یک سفارش بدون قلم گم‌شده ثبت شوند.
- CV-OPS-07-AC02: dispatch و cancel هم‌زمان یک مقدار را هم ارسال و هم لغوشده نکنند.

## مجوز، خطا و بررسی

قواعد نقش/فرم/عملیات سند پنل و scoped DTO سند معماری در تمام دسترسی‌های مرتبط اعمال شوند. بررسی معنادار این گروه: **مقدار بیش‌ازقلم، اقدام نامجاز، مهلت گذشته و رقابت لغو/اعزام**. برای عملیات سرور، پذیرش‌های مثبت/منفی مرتبط با DB/adapter آزمون بررسی شوند؛ برای ظاهر، مرور بصری و تعاملی متناسب کافی است و تست تقلیدی لازم نیست. نوع و نتیجه هر بررسی در گزارش ثبت شود؛ این فایل خود گزارش آزمون نیست.

شناسه تسک، فایل‌های تغییرکرده، رفتار حاصل، نتیجه بررسی‌ها با شاهد، قرارداد مؤثر و مانع باقی‌مانده؛ طبق [فرمت تحویل](../16-agent-delivery.md). همه تسک‌ها در این نسخه todo هستند؛ تهیه سند به معنی شروع یا اتمام کدنویسی نیست.
