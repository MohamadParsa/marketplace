# راهنمای agent برای استفاده از این بسته

نسخه: ۱.۰ | تاریخ: ۲۰۲۶-۱۱-۱۷ | وضعیت: تحلیل و طراحی برای بازبینی تیم فنی | مالک بررسی: محصول و راهبر فنی؛ انتساب شخص هنوز انجام نشده

این پوشه سند تحلیل و طراحی است، نه پروژه اجرایی. بدون مأموریت پیاده‌سازی در پروژه مقصد، کد/نصب/انتشار انجام ندهید. ابتدا README و ۰۱ و سپس فایل task و اسناد مرتبط آن را بخوانید؛ نیازی به خواندن همه taskها نیست.

- قواعد قطعی، قواعد منتقل‌شده، پیشنهاد فنی و CHQ را جدا نگه دارید.
- برای رفتارهای باز امنیتی/مالی پاسخ نسازید؛ فقط بخش وابسته را متوقف کنید.
- scope داده سلر هم‌زمان با permission روی API اعمال شود.
- ورودی مبلغ کلاینت، callback مرورگر، cache و UI مرجع حقیقت مالی نیستند.
- یک task کوچک، یک خروجی قابل بازبینی؛ acceptance و تست ریسک همان task.
- شناسه‌ها و تاریخچه حفظ؛ اصلاح قرارداد و mapping با هم؛ UTF-8 فارسی.
- done با شاهد؛ تست آزمون با پذیرش واقعی تفکیک؛ فرمت تحویل در سند ۱۶.
- خود این بسته به ریپوی D:\Cherriva دست نمی‌زند و مجوز تغییر آن نیست.
