# CV-R2-08 — کروسل اختصاصی با انتخاب و ترتیب دستی کالا

## هدف بیزینسی

بازاریابی بدون کدنویسی، کالاهای منتخب هر ویترین را بچیند.

این کار اصلاح/تکمیل تسک‌های CV-CMS-01، CV-CMS-02، CV-WEB-03 است؛ قابلیت مستقل تکراری یا پیاده‌سازی انجام‌شده محسوب نشود. قواعد صریح را از [مشخصات جاری](../sections-fa.md) و راه‌حل پیشنهادی را از متن زیر بخوانید.

## دامنه و راه‌حل فنی پیشنهادی

product_ids ordered unique؛ picker جست‌وجوی DB و فیلتر scope؛ محصول انتخاب شود نه قیمت ثابت یا offer قفل‌شده. renderer از عرضه نماینده معتبر قیمت بخواند؛ ناموجود/خارج scope/unpublished پس از publish حذف امن شود. افزودن/حذف/بالا/پایین در draft.

## داده و قرارداد پیشنهادی

Section.product-rail source=manual یا منبع محدود؛ query picker صفحه‌بندی‌شده؛ title/more_link و product_ids در payload.

نام endpoint و schema در این سند پیشنهاد قرارداد است؛ در kickoff با OpenAPI پروژه مقصد هماهنگ شود و بدون نسخه‌گذاری با مسیر قدیمی موازی نشود.

## دسترسی و محدوده

pages.edit/publish؛ query فقط کاتالوگ مجاز همان ویترین؛ انتخاب ID دلخواه از API کنترل شود.

## خطا و حالات رابط

PRODUCT_NOT_ELIGIBLE، DUPLICATE_PRODUCT، SECTION_EMPTY، REVISION_CONFLICT؛ وضعیت کالای حذف‌شده واضح.

حالت loading، خالی، خطای شبکه و تلاش مجدد امن، عدم دسترسی و conflict متناسب با همان عملیات لازم‌اند. خطا نباید draft معتبر کاربر را حذف یا موفقیت ساختگی اعلام کند.
