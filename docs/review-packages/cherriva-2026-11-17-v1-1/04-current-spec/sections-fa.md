# سکشن با فرم اختصاصی نوع

شناسه: CV-R2-CMS | نسخه: ۱.۱ | تاریخ: ۲۰۲۶-۱۱-۱۷ | وضعیت: قابلیت‌های اعلام‌شده + schema/UX پیشنهادی در بازبینی | مالک تصمیم: الیاس

مدیریت سکشن به معنی فرم یکسان برای همه نوع‌ها نیست. هسته مشترک فقط شناسه، عنوان، enabled، ترتیب، scope صفحه و revision است. `type` تعیین می‌کند کدام payload و فرم اعتبار دارد. پیشنهاد: discriminated union؛ key یا فیلد نامرتبط با نوع، سمت سرور رد شود. قالب‌های آماده زیر جای صفحه‌ساز آزاد را می‌گیرند.

| نوع | فیلدها و فرم اختصاصی | رفتار سایت |
| --- | --- | --- |
| hero / بنر اصلی | تصویر دسکتاپ، تصویر موبایل، alt، مقصد؛ در صورت چند اسلاید، هر اسلاید همین زوج رسانه و ترتیب دارد | picture/srcset متناسب viewport؛ alt و لینک معتبر؛ متن روی تصویر برش نخورد |
| banner-grid / گروه بنر | فهرست مرتب بنر، هرکدام زوج desktop/mobile، alt و link | ستون‌بندی responsive، نه تکثیر تصویر دسکتاپ روی موبایل |
| product-rail / دستی | جست‌وجوی Product، انتخاب ID، حذف، ترتیب بالا/پایین، عنوان/لینک مشاهده همه | هر Product فقط یک بار؛ قیمت/موجودی از عرضه نماینده معتبر؛ بدون ثبت قیمت در سکشن |
| product-rail / دسته یا تخفیف | دسته/کمپین، حداقل سیاست محصول، سقف، ترتیب و لینک | فقط محصول منتشرشده و قابل خرید؛ منبع با mode دستی مخلوط نشود |
| sticky-banner | زوج تصویر desktop/mobile، alt/link، محل چسبیدن، محدوده صفحه و امکان بستن | موقعیت و رفتار بستن پیشنهاد UX‌اند؛ هم‌پوشانی با خرید/پرداخت ممنوع در معیار پذیرش پیشنهادی |
| category-icons | دسته‌های مجاز یا منبع تعریف‌شده | آیکن سفارشی دسته و fallback داخلی |
| brand-rail | برندها و ترتیب | آیکن/لوگو و fallback برند |
| text | متن محدود و قالب مجاز | بدون اجرای script یا HTML نامطمئن |

کروسل دستی، «محصول» را انتخاب می‌کند؛ تعیین فروشنده نماینده و قیمت از قرارداد مشترک کاتالوگ/قیمت انجام می‌شود. ناموجودشدن یا unpublish پس از انتشار سکشن، کالای غیرقابل خرید را از ریل فروش خارج می‌کند؛ حداقل کمتر از پنج کالا هنوز CHQ-12 است. انتخاب دستی نباید مجوز نمایش کالای غیرمجاز یا نشت scope ویترین gold/digi را بدهد.

پیشنهاد API: `Section {id,type,revision,enabled,payload}`؛ payload بنر شامل `desktop_media_id,mobile_media_id,alt,link` و دستی شامل `product_ids,more_link` است. آرایه فقط ID معتبر و بدون تکرار، ترتیب پایدار و محدودیت سیاست داشته باشد. نوع موجود روی صفحه منتشرشده با تغییر مخرب silent تبدیل نشود؛ تبدیل/جایگزینی به draft جدید روشن نیاز دارد.

در این نسخه طرح، بنر اصلی، گروه بنر جدید، کروسل انتخاب دستی و بنر استیکی فرم متفاوت دارند؛ آپلود preview محلی، picker قابل جست‌وجو و ترتیب دستی قابل بررسی‌اند. ابعاد ۱۴۴۰×۴۸۰ و ۷۵۰×۹۰۰ فقط راهنمای نمونه‌اند؛ اندازه/نسبت هر نوع باید با قالب نهایی تأیید شود. سکشن استیکی به طور پیش‌فرض غیرفعال است و در سایت، حالت نمونه قابل انتخاب دارد.

draft → preview → publish و نسخه مستقل اصلی/gold/digi حفظ می‌شود. فایل/تنظیم نامعتبر مانع انتشار واقعی است. زمان‌بندی، rollback و اندازه فایل/تعداد نهایی، از صرف نمایش یک input نهایی نمی‌شوند. تصمیم‌های باز CHQ-08/12 به جای خود باقی‌اند.
