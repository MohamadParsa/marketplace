# بسته بررسی طراحی چریوا

نسخه ۰٫۴ — ۲۰۲۶-۱۱-۱۷ — وضعیت `in-review`.

سه مسیر **A متعادل و شیک، B فروش‌محور، C لوکس و تصویری** برای Home، PLP، PDP و اکنون سبد، ورود/OTP، نشانی، ارسال، پرداخت و نتیجه خرید، در دسکتاپ و موبایل موجود است. دکمه قبل و بعد از افزودن طبق تصویر کاربر اصلاح شده است. این پوشه طراحی مستقل است؛ برنامه و سایت منتشرشده تغییر نکرده‌اند.

5. [راهنمای فارسی سبد تا پرداخت](checkout-handoff-fa.md) و [راهنمای Home/PLP/PDP](handoff-fa.md).
6. [فهرست تصاویر](image-index-fa.md)، [دلیل اقتباس از مرجع‌ها](reference-adaptations-fa.md)، [دفتر بازخورد](review-notes-fa.md) و [گزارش بررسی](verification-fa.md).

انتخاب نهایی A/B/C یا ترکیب آن‌ها هنوز انجام نشده است. رنگ و لوگوی نهایی بین مسیرها ثابت‌اند. اطلاعات، فروشندگان، مبالغ و نشانی‌ها ساختگی‌اند.

## بازکردن پیش‌نمایش

برای مشاهده بدون نصب ابزار، `index.html` را با مرورگر باز کنید؛ دارایی‌ها و فایل‌ها باید کنار هم بمانند. در صورت استفاده از Node موجود روی سیستم، در همین پوشه اجرا کنید:

```powershell
node serve-design.cjs
```

سپس `http://127.0.0.1:5186` را باز و برای توقف Ctrl+C بزنید. این سرور فقط روی loopback فایل‌های طراحی را نشان می‌دهد؛ برنامه Go/React را اجرا نمی‌کند. نیاز به نصب وابستگی پروژه نیست.

## نکته مهم پیش‌نمایش

هر صفحه با داده ثابت خودش باز می‌شود. تغییر تعداد یا حمل در همان صفحه دیده می‌شود، اما به صفحه بعد منتقل نمی‌شود. OTP و پرداخت واقعی، ذخیره حساب، سبد مشترک، استعلام یا رزرو وجود ندارد. صفحه پرداخت نمایشی به نتیجه «در حال بررسی» می‌رود؛ سایر نتایج از انتخاب حالت نمایشگر قابل دیدن‌اند. تایمرها ثابت‌اند.

نسخه ۰٫۲ در پوشه قبلی حفظ شده است. این نسخه همان روز با دامنه جدید تهیه شده و تاریخچه آن در راهنماها ثبت شده است. تصاویر مرجع برای بررسی داخلی‌اند؛ دارایی انتشار باید مجاز/اختصاصی باشد. تأیید طراحی یا پذیرش سرویس واقعی از این خروجی برداشت نشود.
