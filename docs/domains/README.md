# حوزه‌های کسب‌وکار

این بخش مرجع قواعد مشترک است؛ صفحات و API قانون موازی تعریف نمی‌کنند. مرز حوزه به معنی سرویس مستقل یا جدول دیتابیس نیست.

| حوزه | مسئولیت |
| --- | --- |
| [کاتالوگ](catalog/README.md) | دسته، خصوصیت، ترکیب، فروشگاه و پیشنهاد فروش |
| [قیمت‌گذاری](pricing/README.md) | انتخاب کمیسیون، مبالغ و اعتبار قانون |
| [سبد و پرداخت](checkout/README.md) | سبد، رزرو و جلسه زمان‌دار خرید |
| [هویت](identity/README.md) | ورود مشتری و تکمیل اطلاعات |
| [سفارش](orders/README.md) | تأمین، محدودیت رد، پرونده پشتیبانی و لغو |
| [ارسال](shipping/README.md) | آماده‌سازی، تجمیع، هزینه و برآورد |
| [پرداخت و کیف پول](payments/README.md) | درگاه نقدی/BNPL، گردش اعتبار، برداشت و refund |
| [تسویه](settlements/README.md) | تخصیص پرداخت فروشنده به اقلام سفارش |
| [پیامک](notifications/README.md) | رخداد، گیرنده و استقلال شکست اعلان |

بخش «قواعد تأییدشده» از تصمیم کاربر، و بخش «طراحی پیشنهادی» برای بررسی است. ابهام‌ها در [دفتر پرسش‌ها](../product/open-questions.md) مرجع واحد دارند.
