# واژه‌نامه محصول

| اصطلاح | تعریف |
| --- | --- |
| مشتری / خریدار | کاربر خریدکننده سایت فروش؛ با فروشنده اشتباه نشود. |
| فروشگاه | واحد عرضه که بک‌آفیس ایجاد می‌کند؛ دارای صفحه عمومی، کالا و سفارش‌های مربوط است. |
| فروشنده | کاربر مجاز پنل یک فروشگاه؛ تعداد اعضا و نقش‌های داخلی آن هنوز باز است. |
| محصول | هویت و محتوای عمومی کالا، مستقل از قیمت و موجودی فروشندگان. |
| خصوصیت توضیحی | مشخصه‌ای برای معرفی کالا؛ لزوماً گزینه قابل انتخاب یا قیمت‌ساز نیست. |
| خصوصیت انتخابی | مشخصه دسته‌بندی که مقادیر آن ترکیب قابل خرید را می‌سازند. |
| ترکیب / Variant | ترکیب معتبر گزینه‌ها، مانند رنگ مشکی و وزن از پیش تعیین‌شده. |
| پیشنهاد فروش / Offer | عرضه یک ترکیب توسط یک فروشگاه با قیمت پایه، موجودی و زمان آماده‌سازی خودش. |
| تعداد | شمار واحدهای از پیش تعریف‌شده همان پیشنهاد فروش؛ وزن آزاد نیست. |
| قیمت پایه | مبلغی که فروشگاه برای یک واحد پیشنهاد فروش ثبت می‌کند. |
| کمیسیون | مبلغ پلتفرم که با قانون منتخب یا پیش‌فرض دسته‌بندی محاسبه و با شیوه تعیین‌شده اخذ می‌شود. |
| اعتبار قانون | مهلت قیمت‌گذاری و تمدیدهای آن؛ به معنی ثابت‌ماندن قیمت پایه نیست. |
| جلسه پرداخت / Checkout Session | تلاش زمان‌دار برای نهایی‌کردن سبد با مقصد، ارسال و محاسبات مشخص؛ از تلاش درگاه مستقل است. |
| رزرو موجودی | کنارگذاشتن موقت موجودی برای جلوگیری از فروش هم‌زمان؛ خرید نهایی نیست. |
| خرید / Purchase | نمای کل خرید مشتری با یک پرداخت و یک یا چند سفارش فروشگاهی. |
| سفارش فروشگاهی / Seller Order | بخش خرید متعلق به یک فروشگاه؛ مبنای تجمیع ارسال و توقف عدم تأمین. |
| قلم سفارش | ترکیب و پیشنهاد فروش خریداری‌شده با تعداد و سابقه مالی ثابت. |
| تأیید تأمین | تعهد فروشنده به موجودبودن اقلام؛ با تأیید پرداخت یا ارسال یکی نیست. |
| پرونده عدم تأمین | رسیدگی پشتیبانی به قلمی که فروشنده قادر به تأمینش نیست؛ لغو خودکار نیست. |
| آماده‌سازی | بازه فروشنده از پرداخت قطعی تا آمادگی ارسال، با روز کاری. |
| ارسال / Shipment | تحویل محموله توسط فروشنده با روش حمل منتخب؛ نقطه قطعی آن هنوز نیازمند تعیین است. |
| کیف پول / Wallet | اعتبار و گردش مالی مشتری؛ شارژ نقدی، مصرف خرید و برداشت عملیات متمایزند. |
| BNPL | درگاه خرید اعتباری؛ شارژ نقدی کیف پول نیست و سیاست refund خودش را دارد. |
| بازپرداخت / Refund | برگشت مالی بابت سفارش/قلم به روش مجاز درگاه مبدأ. |
| برداشت / Withdrawal | خروج اعتبار کیف پول به کارت واجد شرایط تا ظرفیت قابل برگشت. |
| تسویه / Settlement | ثبت پرداخت سهم فروشگاه در بک‌آفیس با تخصیص به اقلام سفارش. |
| ثبت ثابت / Snapshot | نسخه اطلاعات مؤثر بر خرید که با تغییر داده جاری بازنویسی نمی‌شود. |
| بک‌آفیس / Backoffice | محیط کاربران داخلی مجاز؛ یک نقش با دسترسی نامحدود فرض نمی‌شود. |
| PWA | تجربه وب قابل استفاده مانند اپ؛ تعهد خرید آفلاین یا push از آن نتیجه نمی‌شود. |

«مشتری» در پرسش قبلی تنظیم کمیسیون/کاتالوگ به تصریح کاربر به فروشنده اصلاح شده است. از این پس در اسناد فقط معنای جدول استفاده شود.
