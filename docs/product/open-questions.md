# دفتر پرسش‌ها و موانع تصمیم

تصمیم‌گیر محصول: مالک محصول/درخواست‌کننده. پاسخ‌های قبلی حذف نشده‌اند؛ شناسه‌ها پایدارند. «باز» یعنی نباید پاسخ حدسی وارد پیاده‌سازی شود. هر تصمیم جدید در سند مرجع اعمال و سپس این ردیف بسته شود. آخرین به‌روزرسانی پاسخ‌ها: ۲۰۲۶-۱۱-۰۷.
