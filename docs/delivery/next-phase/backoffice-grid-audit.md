# نتیجه ممیزی #81

به‌روزرسانی ۲۰۲۶-۱۱-۲۶: توصیف و تصاویر این ممیزی شاهد تحویل قبلی‌اند. طبق دستور جدید مالک، فیلتر ستونی عمومی از DataTable حذف و فرم فیلتر هر صفحه مرجع رابط جاری شد؛ [قرارداد جاری](../../architecture/contracts/backoffice-grids.md) این اصلاح را ثبت می‌کند. جست‌وجو، خروجی مجاز XLSX و صفحه‌بندی باقی‌اند. این اصلاح ظاهری، دامنهٔ مجوز یا پذیرش API همه فهرست‌ها را گسترده نمی‌کند.

جست‌وجوی تمام `DataTable`، `<table>`، paging و فهرست‌های تکراری در `apps/backoffice-web/src` انجام شد. **۲۷محل DataTable** زیر، همه یک جزء مشترک دارند. تنها table بومی در همین جزء است. پنل سلر همان کد را با surface/scope موجود مصرف می‌کند؛ فرم مالی عمومی ادمین برای سلر باز نشده است.

در همه ردیف‌های جدول: search، sort، فیلتر متنی هر ستون، پاک‌سازی، count، paging۲۰/۵۰/۱۰۰، انتخاب و XLSX مشترک برقرار است. «اکشن» یعنی اکشن موجود با مجوز قبلی حفظ شده؛ CRUD مفقود از این جدول نتیجه نمی‌شود. ## حجم واقعی و شکاف سمت سرور

بررسی نشان داد بیشتر صفحات مدیریت از `/backoffice/workspace` داده مجاز کامل را می‌گیرند؛ paging مشترک فقط DOM را محدود می‌کند و انتقال/parse کل workspace را کم نمی‌کند. جست‌وجو/فیلتر تازه صرفاً محلی‌اند و query حساس در URL/log تازه‌ای تولید نمی‌کنند. API کوچک مجوز export از IdentitySnapshot استفاده می‌کند تا کاتالوگ/مالی کامل را برای یک اجازه بارگیری نکند.

**این تحویل مهاجرت جامع به query سمت سرور را انجام نداده است.** مالک پذیرش حجم/فیلتر API هر پنج فرم همان #108/#111/#113/#115/#116 است؛ باید endpoint اختصاصی paged با allowlist ستون/فیلتر، count و همان scope داشته باشند و «تمام نتایج» export را از داده کامل مجاز بسازند، نه صرفاً صفحه بارگیری‌شده. شکاف scope فروشنده در #71 و قرارداد اتمیک/فهرست خرید در #70 پیگیری می‌شوند. #81 زیرساخت/ممیزی را می‌بندد؛ این Issueها بسته یا done نشده‌اند. دایرکتوری نقش‌ها در #112 از این تفکیک مستثنا نیست.

تست مرورگر این تحویل۱۵۰کاربر ساختگی (یک نام شبیه فرمول)، انتخاب در دو صفحه،۱۴۹نتیجه فیلترشده و موبایل۳۹۰px را پوشش می‌دهد. آزمون مولد۱۰هزار ردیف موفق و۱۰۰۰۱ردیف ناموفق است؛ ادعای سنجش۱۰۰هزار رکورد/کارایی production یا بازکردن در نرم‌افزار Excel واقعی نداریم. محدودیت‌ها در گزارش پایان و کامنت Issue نیز باید دیده شوند.
