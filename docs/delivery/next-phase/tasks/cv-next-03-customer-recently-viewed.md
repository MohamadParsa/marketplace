## مسئله و نتیجه بیزینسی

مراجعه دوباره به کالای دیده‌شده آسان شود، مستقل از علاقه‌مندی.

## خواسته تأییدشده مالک

بازدید موفق PDP برای کاربر واردشده ثبت شود؛۵۰محصول از۳۰روز اخیر با حذف تکی/همه و صفحه حساب/منوی پروفایل. محصول پنهان ردیف عمومی قابل حذف داشته باشد؛ مهمان ذخیره/ادغام ندارد.

## طراحی فنی پیشنهادی و داخل دامنه

پیشنهاد: upsert آخرین مشاهده user/product، ترتیب زمان نزولی، dedupe بازدید/Refresh و endpoint شخصی محدود. بازکردن خطا/محصول پنهان بازدید معتبر نشود. این فهرست، منبع رویداد خام Analytics نیست.

نوع کار: `implementation`. برای audit/design/analysis-first، گزارش و تصمیم پیش از اصلاح اجرایی است؛ کار بزرگ پس از تحلیل به زیرتسک قابل تحویل ریز شود. این بسته دامنه کل محصول یا مجوز سرویس بیرونی را گسترش نمی‌دهد.

## مرز مشترک و شرط شروع

مالک #64 را در این نوبت انتخاب کرد؛ اجرای محلی done و سند in-review است. دستور حفظ لوکال بر روال قبلی پوش/بستن تقدم دارد؛ Issue این دسته روی گیت بسته شد؛ تغییرهای بعدی لوکال می‌مانند. طرح **A — متعادل و شیک** و نشان C چریوا مرجع‌اند. تغییر پنل و API و storefront در محدوده همین قابلیت با هم دیده شود؛ قسمت نامرتبط با دلیل کنار گذاشته شود.
