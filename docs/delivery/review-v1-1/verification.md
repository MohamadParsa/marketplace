# کنترل بازنویسی تسک‌های مرحله۲

تاریخ:۲۰۲۶-۱۱-۲۰ | وضعیت: بررسی اسناد/برنامه کار؛ اجرای نرم‌افزار انجام نشده | فرایند: [#14](https://github.com/MohamadParsa/marketplace/issues/14)

## دامنه بررسی

۱۲ تسک #1 تا #12 بر اساس [پاسخ مالک](../../decisions/adr-005-review-v1-1-product-responses.md) بازنویسی و سه کار جدید برای تنظیمات عمومی، ظرفیت اسلات و خبرم‌کن تفکیک شدند. ۱۵ شرح، ۱۲ active/todo و۳ deferred هستند؛ برای هیچ‌کدام شاهد اجرای محصول ساخته نشده است.

## کنترل لازم برای بستن #14

- پاسخ‌های R2-Q01..06 و Q-027/028 به Issue و سند مربوط لینک دارند.
- هر شرح فعال، محدوده/وابستگی و AC و مدرک بستن دارد؛ علت و شرط شروع قسمت‌های blocked صریح است.
- #7/#8/#9 از dependency فعال #11/#12 حذف‌اند؛ source snapshot و manifest آن محفوظ است.
- فلو #3 با موبایل شروع می‌شود؛ ورود مستقل با ایمیل معیار شروع نیست. زیرسایت/نشست بین‌میزبانی معوق‌اند؛ A پنل/سلر قطعی است.
- همگام‌سازی متن و عنوان Issueها با نسخه سند و بازبودن کارهای پیاده‌سازی با خواندن دوباره GitHub بررسی شود؛ نتیجه در این پوشه و کامنت #14 ثبت می‌شود.

[فهرست فعال](README.md) و [JSON شرح‌ها](task-index.json) مرجع متن قابل بررسی‌اند. گزارش ماشین‌خوان کنترل محلی پس از اجرای کنترل‌ها در همین پوشه قرار می‌گیرد؛ این گزارش قبولی API/مرورگر/provider یا مجوز اجرای سیاست باز نیست.

## نتیجه کنترل محلی

[گزارش ماشین‌خوان](local-validation.json): ۱۵ شرح (۱۲ todo و۳ deferred)، گراف۱۰۶ شناسه شامل تسک‌های پایه بدون چرخه و بدون dependency معوق برای کار فعال. ۶۶۴ فایل snapshot با SHA256 اولیه برابرند و برنامه/زیرساخت تغییر نکرده است. تعداد دقیق لینک‌های بررسی‌شده در JSON ثبت شده است.

تطبیق عنوان/متن ۱۵ Issue با شرح‌ها، بدون بستن کارهای پیاده‌سازی، پس از انتشار سند در GitHub خوانده و نتیجه جدا در این گزارش ثبت می‌شود. تکمیل این کنترل‌ها، پایان برنامه‌ریزی #14 است؛ AC نرم‌افزار همچنان شاهد اجرای خودش را لازم دارد.
