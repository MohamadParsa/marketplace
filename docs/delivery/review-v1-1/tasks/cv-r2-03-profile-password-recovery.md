# CV-R2-03 — پروفایل، رمز و بازیابی OTP با شروع ورود از موبایل

## هدف بیزینسی و نتیجه

کاربر پس از ورود نخست، رمز و ایمیل اختیاری ثبت و در صورت فراموشی رمز از مقصد معتبر OTP استفاده کند.

## داخل دامنه

- یک credential برای همان User؛ ایمیل اختیاری و یکتا، بدون ایجاد User دوم.
- ثبت/تغییر رمز در پروفایل؛ پس از ثبت، لینک رمز بعد از موبایل در #2 ظاهر شود.
- بازیابی با OTP موبایل؛ در صورت وجود ایمیل معتبرِ متصل به حساب، انتخاب ارسال OTP به همان ایمیل.

## راه‌حل و داده پیشنهادی

self-profile فقط مالک User؛ hash رمز، challenge محدود و single-use. مقصد دلخواه واردشده در فرم بازیابی حق دریافت کد حساب دیگر ندارد؛ یکتایی ایمیل در سرور.

## دسترسی، خطا و حالات

مجوز هر query و عملیات در سرور و همراه scope انتساب کنترل شود؛ خطای اعتبارسنجی کنار فیلد، loading/empty/error/forbidden و conflict متناسب با عملیات دیده شوند. draft معتبر از بین نرود و retry اثر تکراری ایجاد نکند. برای کار معوق این‌ها معیار فاز فعال‌شده‌اند؛ وجود فرم نمونه شاهد اجرا نیست.

## بخش مسدود، خارج محدوده یا شرط شروع

روش تأیید اولیه ایمیل پیش از فعال‌سازی بازیابی ایمیلی انتخاب شود؛ تا آن زمان فقط قسمت مستقل موبایل/رمز قابل پذیرش است. تغییر موبایل و مسیر فقدان شماره قبلی خارج از scope و منتظر تأیید پیشنهادند.

اصل پنل/سلر کامل با داده آزمون پیش از سایت حفظ شود. مخزن/پروژه، provider، مقررات و تصمیم باز از fixture یا رابط استنباط نشود؛ اتصال واقعی گیت مستقل دارد.

## معیار پذیرش

- CV-R2-03-AC01: ثبت ایمیل خالی مجاز باشد و ایمیل متعلق به User دیگر به این حساب متصل نشود.
- CV-R2-03-AC02: ثبت رمز باعث لینک ورود با رمز برای همان موبایل شود؛ متن خام رمز/OTP در API و log دیده نشود.
- CV-R2-03-AC03: بدون ایمیل، بازیابی با موبایل کامل شود؛ با ایمیل معتبر، کاربر مقصد را انتخاب و OTP اشتباه/منقضی رد شود.

## شاهد پایان پیاده‌سازی

شاهد API برای ایمیل تکراری، همان User و OTP بازیابی؛ مرورگر پروفایل→ثبت رمز→لینک ورود؛ بازیابی ایمیلی فقط با سیاست تأیید منتخب شاهد بگیرد.

گزارش تحویل: شناسه کار، فایل/قرارداد، رفتار قبل/بعد، داده آزمون و نتیجه هر AC، مجوز/scope، موارد باز و لینک شاهد. mock، integration/API، browser و provider مستقل گزارش شوند؛ هیچ نتیجه‌ای در مرحله تدوین این سند ثبت نشده است.
