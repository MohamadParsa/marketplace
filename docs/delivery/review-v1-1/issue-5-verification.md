# نتیجه پیاده‌سازی و بررسی Issue #5

تاریخ:۲۰۲۶-۱۱-۲۰ | قابلیت: CV-R2-05 | وضعیت کد: review، پیاده‌سازی و بررسی محلی انجام‌شده؛ ادغام/استقرار انجام نشده | وضعیت مشخصات: in-review

## رفتار حاصل

قبلاً خصوصیات دسته یک فهرست متن بود. اکنون کتابخانه با شناسه مشترک، نوع، واحد و گزینه وجود دارد؛ ادمین تعریف را می‌سازد و به دسته‌های دلخواه منتسب می‌کند. تغییر محور/کارت/فیلتر/ترتیب در یک دسته، انتساب سایر دسته‌ها را تغییر نمی‌دهد. فرم از گرید دسته در دسترس است و نام مشترک، پیش از ثبت دسته‌های متأثر را نشان می‌دهد.

سقف عمومی کارت در فرم نوع‌دار نمایش و تغییر می‌کند؛ preview از projection سرور می‌آید، نه آرایه ثابت قالب. رنگ و گارانتی محور موبایل، حافظه/رم/دوربین/نمایشگر ویژگی کارت‌اند. شارژر فرزند دیجیتال است ولی حافظه را ارث نمی‌برد. این fixture ساختگی برای آزمون است و دسته‌بندی نهایی کسب‌وکار نیست.

[تست HTTP](../../../apps/api/internal/bootstrap/attributes_test.go) و [خلاصه ماشین‌خوان](issue-5-checks.json) مرجع نتایج‌اند.

## اجرای بررسی‌ها

- `go test ./...` موفق؛ گزارش JSON از اجرای واقعی به خلاصه ماشین‌خوان منتقل شده است.
- `go vet ./...` موفق.
- `npm run lint` و `npm run build` در backoffice-web موفق. هشدارهای غیرمسدودکننده قبلی درباره اندازه bundle و annotation وابستگی باقی‌اند.
- Playwright CLI:۲۲/۲۲ بررسی موفق، بدون pageerror و console error در اجرای نهایی. مرور دسکتاپ۱۴۴۰ و موبایل۳۹۰ پیکسل؛ فرم‌ها و صفحه بدون overflow افقی.
- `go test -race` محلی اجرا نشد؛ CGO و کامپایلر C در دسترس نیستند. CI لینوکس از workflow مخزن آن را جدا اجرا می‌کند و نتیجه GitHub باید مستقل خوانده شود.
- سه سناریوی [BDD](../../bdd/features/experiences/shared-attributes.feature) با همان ACها ثبت شدند؛ runner مستقل Gherkin اجرا نشده است.

برای تکرار مرورگر، از fixture تازه استفاده کنید؛ اجرای موفق داده را تغییر می‌دهد. پس از build وب، API را از `apps/api` با متغیرهای زیر اجرا کنید:

~~~powershell
$env:APP_ENV='test'
$env:PORT='8095'
$env:WEB_ROOT='../backoffice-web/build'
go run ./cmd/api
~~~

سپس از ریشه مخزن:

~~~powershell
npx --yes --package @playwright/cli playwright-cli -s=cherriva-attributes open http://127.0.0.1:8095/
npx --yes --package @playwright/cli playwright-cli -s=cherriva-attributes run-code --filename tests/e2e/shared-attributes.cjs
~~~

## مرز و موارد باز

تعریف و انتساب در adapter حافظه‌ای آزمون ذخیره می‌شوند و با restart پاک می‌شوند. storage واقعی، ویرایش کامل درخت دسته، محصول/ترکیب و عرضه #6، قالب اصلی storefront #11، نقش سفارشی #1 و تنظیمات کامل #15 در این تحویل نیستند.

فقط برش وابستگی `display_settings.card_attribute_limit` از #15 انجام شده است؛ تقویم و سایر گروه‌ها همچنان todo هستند. مقدار۳ صرفاً fixture است؛ انتخاب سقف تولید و سیاست تبدیل آینده محور استفاده‌شده در R2-Q03 بازند. تا آن تصمیم، مجموعه محور دسته دارای محصول و schema تعریف مورد استفاده قفل می‌مانند. قیمت و موجودی و سفارش تاریخی بازنویسی نمی‌شوند.
