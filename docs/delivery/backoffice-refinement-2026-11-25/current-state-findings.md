# یافته‌های تطبیق سورس — ۲۰۲۶-۱۱-۲۵

این‌ها یافته خواندن سورس هستند؛ اصلاح کد در این نوبت انجام نشده است.

| مشاهده | علت/مرز فعلی | پیگیری |
| --- | --- | --- |
| برخی خصوصیات قابل انتخاب/حذف نیستند | `shared-attributes.tsx` حذف binding دارای مقدار محصول یا محور دسته مصرف‌شده را قفل می‌کند؛ محور فقط برای enum و دسته بدون محصول آزاد است. `attributes.go` سمت سرور نیز تغییر مجموعه محور و حذف خصوصیت دارای مقدار را رد می‌کند. هدف حفاظت داده است؛ توضیح و مسیر تبدیل کافی نیست. | #108 UX و علت؛ #109 برنامه تبدیل امن |
| `gsp-axis-color` در پنل دیده می‌شود | snapshot واردسازی ID و Code این خصوصیت را هر دو `gsp-axis-color` دارد؛ دیالوگ پنل مستقیماً `a.code` را نشان می‌دهد. #102 اصلاح مرز عمومی storefront بود و PK/FK/manifest را حفظ کرده بود؛ این نمایش پنل شکاف جداست. | #110 |
| دو مسیر دسته/برند | `ManagementPage` برای ایجاد دسته به `/home-catalog?create=category` می‌رود. `HomeCatalogPage` تب دسته/برند/محصول و فرم‌های ایجاد/ویرایش را نگه داشته و از برند به صفحه آیکن جدا لینک می‌دهد. | #107، #108، #115، #116 |
| «شماره حساب آزمون» | label اشتباه فیلد `phone` در ایجاد کاربر است؛ حساب بانکی نیست. | #111 |
| کاربران بدون ویرایش کامل | فرم ایجاد ساده با `name/phone/role` و بخش access زیر گرید است؛ ایمیل/نام تفکیک‌شده/جنسیت/رمز اولیه موقت و فرم جامع ویرایش admin در این مسیر کامل نیست. هویت واحد و role/grant پایه قبلاً موجودند. | #111 و #112؛ موتور هویت دوباره ساخته نشود |
| فروشگاه | مدل فعلی فقط بخشی از داده خواسته‌شده را دارد: Name/Owner/City/Active/Model/LeadDays و سیاست محتوا. امکانات تازه افزایشی‌اند و وقفه تأمین/عضویت قبلی نباید حذف شوند. | #113 و #114 |
| برند | مدل Name/Active/IconID/Version موجود است؛ ایجاد/ویرایش پایه در فرم تجمیعی هست. انگلیسی/توضیحات و صفحه کامل اختصاصی/فیلتر شکاف تازه‌اند. | #115 |
| ویژگی‌های نمایشی و فیلتر محصول | بله، از binding همان دسته می‌آیند؛ کد فعلی همه bindingهای غیرمحور (`!axis`) را می‌آورد، نه فقط موارد با Card یا Filter=true. مقدار ویژگی متعلق به محصول و نقش/ترتیب نمایش متعلق به دسته است؛ عنوان فرم می‌تواند گمراه‌کننده باشد. | #108 و #116 |
| انتخاب واحد هر محصول | کنترل‌های فعلی عملاً فقط g و mm دارند؛ انتخاب تکراری اجباری UX بی‌فایده است. مقدار فیزیکی حمل با وزن طلا یکی نیست. | #117 |
| مارکاپ دسته در پنل دیده نمی‌شود | #73 هنوز باز است؛ قرارداد محاسبه نقدی/کوپن موجود، روش جاری نقدی با مارکاپ صفر است. بخش «قوانین کمیسیون» جایگزین فرم روش فروش نیست. | تکمیل همان #73 |
