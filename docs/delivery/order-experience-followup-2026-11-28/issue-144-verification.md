# نتیجه #144

فیلتر مستقل mobile در API فهرست سفارش با نرمال‌سازی ارقام و +98 و تطبیق شماره کامل پیش از total/pagination اضافه شد؛ سابقه قدیمیِ بدون مشتری با شماره حدسی تطبیق نمی‌خورد. خروجی و صفحه‌بندی همان query را استفاده می‌کنند و موبایل در payload لیست افشا نمی‌شود. دکمه مشاهده در آخر ردیف به جزئیات موجود می‌رود. Go برای ترکیب وضعیت/فروشگاه، ارقام فارسی/عربی/لاتین، شماره بیگانه/نامعتبر و منع surface مشتری/فروشنده موفق؛ build بک‌آفیس موفق. مرورگر fixture: جست‌وجوی موبایل فارسی از۵ردیف به۱سفارش درست رسید و مشاهده و reload جزئیات همان سفارش کار کردند.

محیط بررسی ساختگی و ایزوله است؛ انتشار عمومی یا تغییر داده کسب‌وکار از این گزارش نتیجه نمی‌شود. کامیت و CI و کامنت بستن در فهرست تحویل نهایی/Issue ثبت می‌شوند.
