# ورود فهرست استان‌ها و شهرهای ایران — ۲۰۲۶-۱۱-۲۷

این گزارش اجرای درخواست مستقیم الیاس برای دریافت اینترنتی و ورود فهرست کشور است؛ وضعیت تأیید مشخصات را تغییر نمی‌دهد. [بسته، منبع و مجوز، روش بازتولید و راهنمای CLI](../../data/iran-geography/README.md) · [قرارداد موجود مدیریت جغرافیا و آدرس](../architecture/contracts/purchase-experience.md).

## داده و نتیجهٔ اجرا

منبع عمومی `sajaddp/list-of-cities-in-Iran`، نسخهٔ `3.1.2` و commit ثابت `ace21bb251f96ced350bbc01541acffd71121feb` است. طبق manifest منبع، داده از تقسیمات کشوری پایان۱۴۰۴ استخراج شده؛ این مخزن واسط دولتی نیست. خروجی پالایش‌شدهٔ شهر، **۳۱ استان و ۱۴۸۱ شهر** دارد. مناطق شماره‌دار شهری حذف شده‌اند؛ نام شش شهر هم‌نام با شهرستان متمایز است. جزئیات در [provenance](../../data/iran-geography/provenance.json) ثبت شده است.

روی PostgreSQL بررسی محلی همین سیستم،۲استان و۳شهر موجود تطبیق داده شدند و **۲۹ استان و۱۴۷۸شهر** اضافه شدند. پنج شناسهٔ `review-tehran`، `review-tehran-city`، `review-rey-city`، `review-qom` و `review-qom-city` عیناً حفظ شدند. یک استان ساختگی غیرفعال و شهر زیرمجموعه‌اش از قبل وجود داشتند؛ حفظ شدند، بنابراین جمع مدیریتی۳۲استان/۱۴۸۲شهر است؛ خروجی عمومیِ فعال دقیقاً۳۱استان/۱۴۸۱شهر است.

نسخهٔ تنظیمات از۱۲به۱۳ و تعداد audit از۵۲۳به۵۲۴ رسید. پشتیبان جغرافیای قبلی در پوشهٔ خصوصی runtime، `imports`، پیش از تراکنش ذخیره شد. هیچ اطلاعات اتصال، دادهٔ خصوصی حساب‌ها یا فایل پشتیبان در مخزن قرار نگرفته است.

API اصلی restart نشد؛ `GET /storefront/commerce/config` بلافاصله۳۱/۱۴۸۱را برگرداند و شهر کیش با شناسهٔ `ir-c-1220003002193` قابل دریافت بود.

## رفتار پنل و آزمون

استان‌ها ابتدا بسته‌اند؛ کنترل شهرهای بسته mounted نمی‌شود. هنگام بازشدن هر استان،۵۰شهر اول و سپس «نمایش شهرهای بیشتر»۵۰تایی نمایش داده می‌شوند. جست‌وجوی استان/شهر با یکسان‌سازی حروف فارسی و فاصله، فقط ردیف‌های مرتبط را باز می‌کند. شمارهٔ اصلی شهر در ویرایشِ نتایج فیلترشده حفظ می‌شود؛ افزودن شهر/استان، ردیف تازه را قابل دیدن می‌کند. محدودیت نمایش، دادهٔ ذخیره را کم نمی‌کند.

شواهد فنی:

- آزمون‌های Go برای فایل واقعی۳۱/۱۴۸۱، رفع ابهام، حفظ شناسه/غیرفعال/سفارشی، رد JSON نامعتبر، برخورد شناسه، conflict و واردسازی هم‌زمان موفق شدند.
- اجرای dry-run، apply و repeat روی schema مستقل `geography_review_20261127` موفق بود: نسخه۱→۲، audit۰→۱، حفظ هر۵شناسهٔ fixture و hash یکسان سایر داده‌ها. تکرار، no-op بود.
- آزمون HTTP با کل فهرست: خواندن و ذخیرهٔ مجدد ادمین موفق، ویرایش با کاربر فاقد مجوز۴۰۳، ساخت آدرس کیش/هرمزگان موفق و زوج کیش/البرز با `address_unavailable` رد شد؛ تمام داده‌ها fixture حافظه‌ای بودند.
- `go test ./...` با PostgreSQL و Redis محلی و `go vet ./...` موفق شدند. اجرای محلی race به‌علت نبود CGO/compiler ممکن نبود؛ شاهد race لینوکس از CI آخرین کامیت گرفته می‌شود.
- `npm run lint` و `npm run build` بک‌آفیس موفق؛ هشدار موجود اندازهٔ bundle همچنان هست.

مرورگر روی build تازهٔ بک‌آفیس:۳۲استان مدیریتی با صفر کنترل شهر در حالت بسته؛ بازکردن تهران۵۰شهر و «بیشتر»۵۵شهر؛ جست‌وجوی کیش تنها یک ردیف زیر هرمزگان. افزودن شهر در حالت جست‌وجو، جست‌وجو را پاک و ردیف تازه را نمایان کرد؛ این تغییر ذخیره نشد و با خروج از صفحه کنار گذاشته شد.
