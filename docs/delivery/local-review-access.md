# دسترسی تیم به نسخه محلی چریوا

این راهنما به درخواست صریح الیاس برای استفاده مشترک تیم ثبت شده است. حساب زیر روی PostgreSQL نسخه محلی بررسی وجود دارد؛ سرویس‌های این بررسی با `BIND_HOST=127.0.0.1` فقط روی loopback اجرا می‌شوند؛ اطلاعات ورود لیارا از این سند نتیجه نمی‌شود.

| مورد | مقدار |
| --- | --- |
| بک‌آفیس محلی | http://localhost:8098 |
| سایت محلی | http://localhost:5197 |
| نام کاربری ادمین | `09125056182` |
| رمز عبور | `Cherriva123` |
| روش ورود | شماره موبایل ← ادامه ← ورود با رمز عبور |

اگر پارسا روی همان سیستم مرورگر را باز کند، همین آدرس‌ها قابل استفاده‌اند. localhost در سیستم دیگر به همان سیستم اشاره می‌کند؛ برای بررسی روی دستگاه دیگر باید سرویس و دیتابیس همان محیط اجرا شوند. این اطلاعات به معنی ساخت خودکار همین حساب روی محیط تازه یا انتشار روی لیارا نیست.

داده‌های کاتالوگ/تصاویر نسخه بررسی و ورود این حساب پس از راه‌اندازی دوباره PostgreSQL و API حفظ می‌شوند. اجرای فعلی از buildهای React و Go و دیتابیس محلی مشترک استفاده می‌کند. مسیر سورس `D:\Cherriva` است؛ راه‌انداز [Start-Cherriva.ps1](../../Start-Cherriva.ps1) داخل مخزن از مسیر خودش اجرا می‌شود.

```powershell
Set-Location D:\Cherriva
.\Start-Cherriva.ps1
# اگر build تازه دارید:
.\Start-Cherriva.ps1 -NoBuild
```

روی این سیستم PostgreSQL نسخه بررسی در پوشه خصوصی runtime موجود است و راه‌انداز آن را در صورت توقف بالا می‌آورد. روی سیستم دیگر، ابتدا Go سازگار با `apps/api/go.mod`، Node/npm و PostgreSQL جداگانه آماده و `REVIEW_DATABASE_URL` تنظیم شود؛ راه‌انداز وابستگی‌ها و دو frontend را build می‌کند و API را فقط روی loopback اجرا می‌کند. حساب این جدول فقط در دیتابیس بررسی همین سیستم ساخته شده است. برای محیط عمومی از دیتابیس بررسی یا رمز نمونه استفاده نشود. اطلاعات اتصال دیتابیس در گیت ثبت نمی‌شود.
