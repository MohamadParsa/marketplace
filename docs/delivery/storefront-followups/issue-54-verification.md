# نتیجه #54

VariantAxis هر محور را مستقل نشان می‌دهد: در نمای اولیه حداکثر۶چیپ، سه ستون و دو ردیف با فاصله۸ و حداقل ارتفاع۴۴پیکسل. «مشاهده همه» تمام گزینه‌های همان محور را باز می‌کند. اگر منتخب بیرون شش گزینه اول باشد، در جای ششم جای می‌گیرد؛ گزینه حذف یا از API/مدل پاک نمی‌شود. برای حداکثر۶گزینه کنترل اضافه نمایش داده نمی‌شود. این اندازه‌ها انتخاب اجرایی طرح A هستند و تصویب کل مشخصات نیستند.

دکمه‌ها aria-pressed، نام کامل و title دارند؛ label بلند در خود چیپ ellipsis و در legend منتخب کامل است. Enter/Space، focus، RTL، Refresh/Back و جمع‌کردن مستقل دو محور حفظ‌اند. Dropdown جدیدی ساخته نشده است. overlay مشترک #51 همچنان هنگام resolve انتخاب/selection استفاده می‌شود.

## ترتیب عددی بدون تغییر داده

API موجود برای محور unit را نیز برمی‌گرداند؛ فقط تایپ React کامل شد. گزینه‌های عددی با واحد مشترک صریح، یا برچسب‌های صریح g/mg/گرم/میلی‌گرم مرتب می‌شوند. برای همین واحدهای شناخته‌شده، یک گرم برابر۱۰۰۰میلی‌گرم با جابه‌جایی اعشار دقیق مقایسه می‌شود؛ float و گردکردن قیمت/وزن وجود ندارد. ارقام فارسی/عربی و ممیز فارسی فقط برای مقایسه نرمال می‌شوند؛ label و مقدار ارسالی variant/URL همان رشته اصلی‌اند. برای واحد/قالب مبهم، ترتیب تعریف‌شده سرور حفظ می‌شود؛ مثقال و تبدیل حدسی نداریم. محوری که metadata واحد مشترک دارد و مقادیرش عددی‌اند فقط در همان واحد مرتب می‌شود، بدون تبدیل به واحد دیگر.

ساخت/حذف تنوع، قیمت‌گذاری طلا، داده اصلی و سرور تغییر نکردند. انتخاب دومحوری همان قواعد جاری exact و fallback به تنوع موجود در محصول را دارد؛ option بدون هیچ ترکیب تعریف‌شده غیرفعال و تنوع تعریف‌شده ناموجود قابل مشاهده ولی غیرقابل خرید است.
