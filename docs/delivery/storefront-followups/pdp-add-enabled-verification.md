# نتیجه محلی

به ترتیب صریح مالک، ابتدا تمام تغییرات چهار قابلیت در شاخه `codex/checkout-coupons-credit-warranty` و [PR #94](https://github.com/MohamadParsa/marketplace/pull/94) پوش شدند: سورس `1dd7ccd616ba0d6380ce75adcdf9aaf38310a64d` و سرشاخه مدارک انتشار `7f5d25920a3fca0428769a1d8b3bd6c2d09f50e7`. ادغام/استقرار انجام نشده است. **پس از موفقیت پوش**، اصلاح این سند به‌صورت لوکال انجام شد و هنوز کامیت/پوش نشده است.

علت دکمه غیرفعال، فلگ توقف پیش‌فرض در `product-page.tsx` بود: نبود `VITE_PDP_ADD_TO_CART=true` هم توقف محسوب می‌شد. اکنون حالت پیش‌فرض فعال است و فقط مقدار صریح `false` افزودن تازه را متوقف می‌کند. فایل نمونه محیط و README همان app هم مطابق این رفتار اصلاح شدند. شرط موجودی، اعتبار عرضه، بارگذاری و کنترل سمت سرور پابرجاست؛ همان کنترل منتخب قبلی و شمارنده تعداد استفاده می‌شود.

## بررسی

- `npm run lint` و `npm run build` برای storefront موفق؛ build جدید `index-CB97PjFY.js` از سرور فعلی محلی خوانده و با پاسخ۲۰۰ تطبیق شد.
- **۱۲ بررسی مرورگر موفق**: یک کنترل فعال در دسکتاپ، overlay هنگام افزودن، دوبار کلیک و فقط یک ثبت واقعی، popup با لینک سبد، تبدیل همان کنترل به شمارنده، حذف و بازگشت دکمه، افزودن در موبایل، مشاهده محصول در صفحه سبد، پاک‌بودن سبد مهمان پس از تست، حفظ ممنوعیت خرید ناموجود و نبود runtime pageerror.
- تست روی محصول واقعی کاتالوگ محلی [chr-10082](http://localhost:5197/product/chr-10082)، در context مستقل مهمان انجام شد؛ هیچ سفارش، واریز یا پرداختی ساخته نشد و اقلام سبد آزمون در پایان حذف شدند. حالت ناموجود با پاسخ عمومی شبیه‌سازی شد؛ موجودی کاتالوگ واقعی تغییر نکرد.
- تغییر بک‌اند یا وابستگی نداشت؛ آزمون سرتاسری UI/API برای این اصلاح کوچک کافی بود. [نتیجه ماشین‌خوان](pdp-add-enabled-checks.json) · [اسکریپت مرورگر](../../../tests/e2e/pdp-add-enabled.cjs).

[تصویر دسکتاپ](../../../output/playwright/pdp-add-enabled/desktop.png) · [تصویر موبایل](../../../output/playwright/pdp-add-enabled/mobile.png) · [سورس کنترل PDP](../../../apps/storefront-web/src/product-page.tsx).

برای مشاهده http://localhost:5197 را تازه‌سازی کنید. این تغییر فعال‌سازی جزو بسته پوش‌شده قبلی نیست و طبق سیاست تغییرات بعدی، تا دستور صریح بعدی لوکال می‌ماند.
