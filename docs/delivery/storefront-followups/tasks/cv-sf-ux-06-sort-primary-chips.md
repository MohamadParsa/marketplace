# CV-SF-UX-06 — چیپ مرتب‌سازی بدون radio نمایان و با رنگ کامل primary

## مسئله و نتیجه

مرتب‌سازی شبیه انتخاب چیپ در طرح A دیده شود و دایره radio ظاهر آن را شلوغ نکند.

## دامنه و وضعیت

سایت مشتری؛ مهمان و مشتری واردشده. **فقط برنامه‌ریزی؛ شروع اجرا پس از انتخاب صریح مالک**. اولویت P3 پیشنهادی است و ترتیب ثبت، صف اجرای اجباری نیست. طرح A، primary فعلی و لوگوی C چریوا مرجع‌اند. قواعد خصوصی/مجوزهای جاری حفظ شوند. [صف و مرز مشترک](../ux-followups.md).

## خواسته قطعی مالک

- radio نمایان از چیپ‌های sort حذف شود و تمام سطح چیپ انتخاب‌شده رنگ primary بگیرد.

## طراحی اجرایی پیشنهادی

- استفاده از tokenهای رنگ فعلی و متن با کنتراست مناسب؛ انتخاب تک‌گزینه‌ای با radio مخفیِ قابل دسترس یا الگوی ARIA معادل حفظ شود.
- فقط تغییر ظاهر/تعامل گروه sort؛ توکن sort، ترتیب نتایج، پیش‌فرض و query URL مستقل از این تسک باقی بمانند.

## حالت‌های جایگزین و کنترل صحت

داده خالی/کم‌تعداد، خطا و retry، شبکه کند، انتخاب قبلی، Refresh/Back و نمایش موبایل بررسی شوند؛ جزئیات مرتبط در پذیرش زیر آمده‌اند. داده آزمون ساختگی/ایزوله باشد و حساب، سفارش یا مالی واقعی برای نمایش تغییر نکند. در کار نمایشی، مجوز یا mutation تازه‌ای ایجاد نشود؛ در کار دارای API همان کنترل مالکیت و مجوز فعلی برقرار بماند.

## پذیرش

- CV-SF-UX-06-AC01: چیپ منتخب تمام سطح primary و متن خوانا داشته باشد؛ دایره radio در حالت عادی/focus/انتخاب دیده نشود.
- CV-SF-UX-06-AC02: در هر لحظه فقط یک گزینه فعال باشد؛ focus، کلیدهای انتخاب و اعلان دسترس‌پذیر حالت برقرار بمانند.
- CV-SF-UX-06-AC03: Refresh/Back و URL همان sort را بازیابی کنند؛ default و sortهای قبلی عوض نشوند.
- CV-SF-UX-06-AC04: گزینه پرفروش‌ترین اگر هنگام اجرا اضافه شده باشد خودکار همین ظاهر را بگیرد؛ ساخت خود آن گزینه شرط انجام این تسک نیست.

## مرز با تسک‌های دیگر

از CV-SF-UX-01 مستقل است: این کار فقط ظاهر sort، آن کار سنجه و API پرفروش‌ترین را پیاده می‌کند. Switchها در CV-SF-UX-05 هستند.
