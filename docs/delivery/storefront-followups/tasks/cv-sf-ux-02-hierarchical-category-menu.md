# CV-SF-UX-02 — منوی بازشونده درختی دسته‌ها و خالی‌ماندن ادامه نوار اصلی

Issue: [#46](https://github.com/MohamadParsa/marketplace/issues/46) · اساین: `eliassarband` · وضعیت GitHub: **closed؛ کامنت پایان ثبت شد** · شروع اجرا: به درخواست مالک.

## مسئله و نتیجه

ناوبری اصلی دسته‌ها از نمایش لینک‌های پراکنده به منوی قابل فهم والد/فرزند تبدیل شود.

## دامنه و وضعیت

سایت مشتری؛ مهمان و مشتری واردشده. **به درخواست مالک اجرا و محلی آزموده شد**. اولویت P2 پیشنهادی است و ترتیب ثبت، صف اجرای اجباری نیست. طرح A، primary فعلی و لوگوی C چریوا مرجع‌اند. قواعد خصوصی/مجوزهای جاری حفظ شوند. [صف و مرز مشترک](../ux-followups.md).

## خواسته قطعی مالک

- با انتخاب دکمه «دسته‌بندی کالاها»، منوی بازشونده باز شود؛ دسته‌های ریشه نودهای اصلی و فرزندان در submenuهای درختی باشند.
- پس از همان دکمه، بقیه سطر منوی اصلی خالی بماند؛ منوی ویژه، لینک تبلیغی یا placeholder تازه افزوده نشود.

## طراحی اجرایی پیشنهادی

- استفاده از navigation فعلی با parent_id و URL canonical؛ ترجیحاً بدون endpoint/مدل منوی جدا و بدون منوی context بومی سیستم‌عامل.
- ریشه/فرزند قابل پیمایش و مسیرهای عمیق، با لینک مستقل خود دسته و کنترل بازکردن شاخه؛ در موبایل نمایش accordion یا drill-down پیشنهاد است، نه dropdown فرم.
- منو با کلیک/لمس و کیبورد قابل استفاده باشد، صرفاً به hover وابسته نباشد؛ Escape و کلیک بیرون ببندند و focus برگردد. انتشار اجداد رعایت شود. قاعده دسته‌های موجود زیر بنر خانه جدا و دست‌نخورده می‌ماند؛ موجودی شرط تازه‌ای برای این منو فرض نشود.

## حالت‌های جایگزین و کنترل صحت

داده خالی/کم‌تعداد، خطا و retry، شبکه کند، انتخاب قبلی، Refresh/Back و نمایش موبایل بررسی شوند؛ جزئیات مرتبط در پذیرش زیر آمده‌اند. داده آزمون ساختگی/ایزوله باشد و حساب، سفارش یا مالی واقعی برای نمایش تغییر نکند. در کار نمایشی، مجوز یا mutation تازه‌ای ایجاد نشود؛ در کار دارای API همان کنترل مالکیت و مجوز فعلی برقرار بماند.

## پذیرش

- CV-SF-UX-02-AC01: با انتخاب دکمه دسته‌بندی، ریشه‌ها و زیرشاخه‌های واقعی حداقل سه‌سطحی از parent_id ساخته شوند؛ دسته بدون فرزند قابل بازکردن PLP باشد.
- CV-SF-UX-02-AC02: هر لینک دسته به slug همان دسته برود؛ شاخه پنهان/نامنتشر وارد منوی عمومی نشود و درخت/قاعده PLP محصولات مستقیم تغییر نکند.
- CV-SF-UX-02-AC03: در دسکتاپ و موبایل، لمس و کیبورد، بستن و بازگشت focus و جلوگیری از overflow بررسی شوند؛ منو فقط hover نباشد.
- CV-SF-UX-02-AC04: ادامه همان ردیف کنار دسته‌بندی کالاها خالی باشد؛ لوگو، سرچ و آیکن‌های ردیف بالایی برقرار بمانند.
