# CV-SF-UX-08 — ارتفاع محدود معرفی و مشخصات فنی PDP با مشاهده بیشتر/کمتر

Issue: [#52](https://github.com/MohamadParsa/marketplace/issues/52) · اساین: `eliassarband` · وضعیت GitHub: **open** · شروع اجرا: منتظر انتخاب مالک.

## مسئله و نتیجه

توضیحات بلند و جدول مشخصات، پیمایش اولیه صفحه محصول را بیش از حد طولانی نکنند.

## دامنه و وضعیت

سایت مشتری؛ مهمان و مشتری واردشده. **فقط برنامه‌ریزی؛ شروع اجرا پس از انتخاب صریح مالک**. اولویت P2 پیشنهادی است و ترتیب ثبت، صف اجرای اجباری نیست. طرح A، primary فعلی و لوگوی C چریوا مرجع‌اند. قواعد خصوصی/مجوزهای جاری حفظ شوند. [صف و مرز مشترک](../ux-followups.md).

## خواسته قطعی مالک

- بخش‌های معرفی محصول و مشخصات فنی در PDP ارتفاع محدود و امکان «مشاهده بیشتر» داشته باشند.

## طراحی اجرایی پیشنهادی

- پیشنهاد: clamp واکنش‌گرا و fade ظریف برای محتوای واقعاً بلند، دکمه مشاهده بیشتر/کمتر با aria-expanded/controls؛ ارتفاع دقیق در زمان اجرای طرح A انتخاب و ثبت شود.
- متن قالب‌بندی‌شده و مشخصات کامل در DOM/داده حفظ شوند؛ HTML با بریدن رشته خراب نشود، پاک‌سازی امنیتی موجود برقرار بماند و API برای این تغییر متن کامل را truncate نکند.
- کنترل فقط وقتی overflow واقعی هست دیده شود؛ تصاویر/فونت/تغییر اندازه و لینک‌های داخل بخش بسته از نظر focus بررسی شوند.

## حالت‌های جایگزین و کنترل صحت

داده خالی/کم‌تعداد، خطا و retry، شبکه کند، انتخاب قبلی، Refresh/Back و نمایش موبایل بررسی شوند؛ جزئیات مرتبط در پذیرش زیر آمده‌اند. داده آزمون ساختگی/ایزوله باشد و حساب، سفارش یا مالی واقعی برای نمایش تغییر نکند. در کار نمایشی، مجوز یا mutation تازه‌ای ایجاد نشود؛ در کار دارای API همان کنترل مالکیت و مجوز فعلی برقرار بماند.

## پذیرش

- CV-SF-UX-08-AC01: معرفی بلند و مشخصات فنی پرردیف هر کدام مستقل جمع و باز شوند؛ بستن یکی وضعیت دیگری را بی‌دلیل تغییر ندهد.
- CV-SF-UX-08-AC02: بخش کوتاه یا خالی کنترل غیرضروری نداشته باشد؛ بازشدن همه متن/ردیف‌ها را بدون قطع پاراگراف/خرابی HTML نشان دهد.
- CV-SF-UX-08-AC03: کیبورد و screen reader وضعیت باز/بسته را بفهمند؛ focus به لینک پنهان‌شده نرود و بستن کاربر را در جای نامرتبط پرت نکند.
- CV-SF-UX-08-AC04: عرض۳۹۰/۱۴۴۰، resize و حفظ HTML پاک‌سازی‌شده، اطلاعات کامل و رفتار SEO بررسی و تصاویر ثبت شوند.
