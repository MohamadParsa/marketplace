# گرید و خروجی — #81

[ماتریس تمام فهرست‌ها و مالکان شکاف‌ها](../../delivery/next-phase/backoffice-grid-audit.md) · [شواهد](../../delivery/next-phase/issues-73-81-verification.md). مرجع اجرا [DataTable](../../../apps/backoffice-web/src/shared/components.tsx)، [XLSX](../../../apps/backoffice-web/src/shared/xlsx.ts) و [مجوز](../../../apps/api/internal/application/backoffice/grid_export.go) است.

## تصمیم‌های تأییدشده

خروجی واقعی XLSX از تمام نتایج فیلترشده یا انتخاب‌های همان نتیجه، با ترتیب جاری و سقف۱۰هزار ردیف. ستون‌های نمایشی مجاز همان گرید صادر شوند؛ رمز، کد ملی و اطلاعات بانکی در خروجی عمومی گرید نباشند. طرح A و اجزای موجود حفظ شوند؛ کتابخانه گرید تازه اضافه نشده است. دستور جدید مالک در ۲۰۲۶-۱۱-۲۶، فیلتر ستونی شبیه Excel در رابط را کنار می‌گذارد؛ فرم فیلتر مشخص بالای نتایج، ظاهر واحد گرید و منوی panelbar داخل سایدبار جایگزین‌اند. این تغییر درخواست مستقیم مالک است و نیازمند پرسش محصول تازه نیست.

## رفتار مشترک

- فرم فیلتر هر صفحه بالای نتایج و با ظاهر مشترک پنل؛ فیلتر ستونی/بازشوندهٔ عمومی از DataTable حذف شده است. برای داده محلیِ فاقد فرم جست‌وجوی اختصاصی، جست‌وجو در متن نمایشی با نرمال‌کردن ی/ک و پاک‌سازی باقی است؛ صفحات کاتالوگ جست‌وجوی موازی دوم ندارند. count و sort پایدار locale فارسی با tie=id حفظ می‌شود. فیلترهای تخصصی تاریخ/مبلغ/درخت در فرم همان صفحه‌اند.
-۲۰/۵۰/۱۰۰ردیف در صفحه؛ تغییر نتیجه/ترتیب صفحه را به ابتدا می‌برد. انتخاب در چند صفحه حفظ، export منتخب با نتیجه فیلتر فعلی intersect می‌شود. اکشن عملیات sticky و در عرض محدود قابل دسترس است؛ خطای خروجی فیلتر را پاک نمی‌کند.
- جزء مشترک حالت remote برای فرم‌های دارای API اختصاصی دارد؛ فیلتر، count و صفحه‌بندی آن‌ها از سرور می‌آید و نوار محلی موازی ساخته نمی‌شود. حالت محلی برای فهرست‌های باقی‌مانده روی داده مجاز دریافت‌شده کار می‌کند؛ حذف workspace کامل در همه مسیرها ادعا نمی‌شود. روش‌های حمل #121 نیز یک صفحه‌بندی remote دارند و export تمام نتایج از همه صفحات مجاز خوانده می‌شود.

## مجوز و حفاظت

`POST /backoffice/grids/export-authorize` و `POST /seller/grids/export-authorize` بدون دریافت id/ستون/داده، مجوز فعلی `grid.export` را بررسی می‌کنند؛ پاسخ۲۰۴، بدون نشست۴۰۱، منع۴۰۳، بدون cache. admin پیش‌فرض و نقش سفارشی قابل انتساب است؛ برای workspace ترکیبی سلر، مجوز در **تمام فروشگاه‌های عضوشده** لازم است. نبود مجوز یکی، کل خروجی را رد می‌کند.

API هیچ داده‌ای برنمی‌گرداند؛ فایل فقط از سلول‌های قابل مشاهده workspace/جزئیات scoped موجود ساخته می‌شود، نه JSON شیء کاربر یا سفارش. ستون عملیات و ستون حساس حذف می‌شوند؛ متن دستور بانکی بازپرداخت اصلاً ستون جدول نیست. خروجی JSON قدیمی گزارش که مجوز export را دور می‌زد حذف و XLSX مشترک جایگزین شد. scope اولیه داده همچنان مسئولیت API موجود و ممیزی #71 است؛ این تحویل ادعای حل همه یافته‌های #71 ندارد.

## فایل و حدها

OOXML در ZIP با CRC، worksheet راست‌به‌چپ، header ثابت و autofilter؛ همه سلول‌ها inline string هستند، حتی اعدادِ قالب‌بندی‌شده و متنی که با `=`/`+`/`@` شروع شود. فرمول، macro یا external relationship ساخته نمی‌شود. تحلیل عددی Excel نیازمند تبدیل متن به عدد است و در این نسخه نوع عددی ادعا نمی‌شود.

حداکثر۱۰هزار ردیف،۱۰۰ستون،۳۲۷۶۷کاراکتر سلول،۵میلیون کاراکتر ورودی و۲۰MiB برای هر جزء XML؛ بیشتر از حد با پیام رد می‌شود، نه برش خاموش داده. تولید دوره‌ای کنترل را آزاد می‌کند و با AbortSignal قابل لغو است؛ خروج از جزء نیز عملیات را لغو می‌کند. خطای اتصال/مجوز/حجم و لغو در همان جدول دیده می‌شود. خروجی در مرورگر ساخته می‌شود و job دائمی یا اطلاعات مالی در سرور ایجاد نمی‌کند.
