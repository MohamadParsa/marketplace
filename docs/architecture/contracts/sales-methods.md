## عملیات و دسترسی

- `GET /backoffice/commerce/sales`: مجوز `commerce.sales.read`؛ خروجی version،methods،overrides،payment_methods،can_write.
- `PUT /backoffice/commerce/sales`: مجوز قابل انتساب `commerce.sales.write`، هدر `Idempotency-Key` و version جاری؛ کل دایرکتوری اتمیک ذخیره می‌شود. admin و مالی پیش‌فرض مجازند؛ مشاهده برای عملیات/پشتیبانی نیز ممکن است. سلر اجازه تنظیم نرخ عمومی ندارد.
- `GET /storefront/products/{id}/sales?variant=...&offer=...`: عمومی، بدون cache HTTP؛ فقط عرضه عمومی معتبر و روش فعال/مجاز همان کالا. شناسه‌های عمومی chr توسط لایه مرجع موجود تبدیل می‌شوند. این فقط پیش‌نمایش یک قلم بدون ارسال/کوپن است؛ مبلغ نهایی در checkout تعیین می‌شود.
- UI: `/sales-methods`؛ اکشن «مارکاپ روش فروش» در دسته و اکشن همان فرم در مسیر تجمیعی موقت. انتخاب پرداخت در UI مالک قبلی را با توضیح صریح منتقل می‌کند؛ API نگاشت تکراری را رد می‌کند.

حدها:۱۰۰روش،۲۰هزار override،نام۱۰۰کاراکتر، شناسه۶۴بایت، درخواست۲MiB؛ نرخ override باید صریح و غیرnull باشد. نام/نرخ/پرداخت نامعتبر۴۰۰، بدون نشست۴۰۱، بدون مجوز۴۰۳، نسخه یا کلید متعارض۴۰۹؛ ورودی UI در خطا محفوظ می‌ماند. retry یک کلید/بدنه، نتیجه قبلی را می‌دهد؛ مجوز فعلی پیش از retry نیز کنترل می‌شود.

## ماندگاری، کش و سازگاری

داده به JSON خصوصی commerce اضافه شده؛ جدول/مهاجرت جدید لازم نیست و migrationهای پایه اجرا می‌شوند. نبود sales در داده قدیمی، نقدی۰٪ با پرداخت‌های غیرکیف‌پولی فعلی تولید می‌کند. ارقام آزمایشی به دیتابیس بررسی اصلی تحمیل نشده‌اند. تغییر معتبر، dependency عمومی کاتالوگ را در همان تراکنش تازه می‌کند؛ projection شامل نرخ/محدودیت عمومی است و حساب/دفتر/مقصد بانکی را ندارد.

سود مستقیم فقط اختلاف قیمت مرجع و نقدی است؛ مارکاپ/کوپن/کیف پول آن را بزرگ نمی‌کنند. لغو از line/discount/credit snapshot موجود استفاده می‌کند. ثبت دفتر و تخصیص وجه همان موتور قبلی است؛ دفتر موازی ساخته نشده.

## مرز تحویل و طراحی بعدی

این برش قیمت نقدی ثبت‌شده را مصرف می‌کند؛ فرمول طلا/کمیسیون #72، مجوز/نام روش فروش برای هر فروشگاه #114، لندینگ #91 و provider واقعی در دامنه این تحویل نیستند. فروشگاه غیرفعال/عرضه نامعتبر طبق کنترل خرید فعلی رد می‌شود؛ قواعد تازه store-method پس از #114 به resolver وصل می‌شوند. فعال‌شدن BNPL از وجود فرم روش فروش نتیجه نمی‌شود.
