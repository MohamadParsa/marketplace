# قرارداد تکمیل نظرات — #119

## خواسته تأییدشده

پنج ستاره طلایی در نظر و فرم ثبت نظر؛ میانگین نظرات تأییدشده همان محصول. طبق اصلاح مالک، نمایش ستاره‌ها یکدست و ظریف باشد و میانگین در بالای PDP نزدیک نام و کد محصول هم دیده شود. ثبت/تأیید نظر از همان سرویس #89 است و تغییر سیاست ثبت یا دسترسی در این کار نیست.

## طراحی اجراشده

`GET /storefront/products/{id}/reviews` علاوه بر صفحه نظرات، `rating_summary: {count, average}` می‌دهد. count تعداد تمام نظرات approved با امتیاز صحیح۱..۵ همان ProductID است؛ cursor و اندازه صفحه در آن اثر ندارند. pending/rejected، محصول دیگر و امتیاز قدیمی نامعتبر محاسبه نمی‌شوند. صفر رأی با count=0 و average=null است. میانگین با جمع/تعداد صحیح، نیم‌به‌بالا تا یک رقم اعشار محاسبه می‌شود؛ ۵و۳→۴٫۰ و۴،۴،۵→۴٫۳. این قرارداد جمع‌بندی عمومی است؛ پنل از پاسخ موجود خود استفاده می‌کند.

خواندن PostgreSQL، دید عمومی کاتالوگ، صفحه نظرات و count/sum را در یک statement snapshot می‌گیرد؛ workspace خصوصی و حساب‌ها/دفتر مالی در این مسیر decode نمی‌شوند. مسیر memory همان قواعد را دارد. aggregate ماندگار یا کش موازی ساخته نشده است؛ API و fetch کلاینت no-store هستند، با بارگذاری تازه/بازگشت focus نتیجه جدید دیده می‌شود. تأیید از فرمان مجاز موجود فوراً بر خواندن بعدی اثر می‌گذارد؛ تکرار همان تصمیم رأی مضاعف نمی‌سازد. این تسک API تازه‌ای برای حذف، تغییر امتیاز یا پس‌گرفتن تأیید اضافه نمی‌کند؛ آزمون تغییر eligibility فقط تغییر fixture ذخیره‌شده را شبیه‌سازی می‌کند.

داده پنهان/منتشرنشده از کنترل عمومی قبلی عبور نمی‌کند؛ نام/متن pending، هویت و اطلاعات خصوصی به summary وارد نمی‌شوند. خاموش‌کردن پذیرش نظر، تاریخچه تأییدشده را پنهان نمی‌کند. اعتبارسنجی و مجوز تصمیم، idempotency و ثبت نظر۱..۵ موجود برقرارند.

## نمایش و تجربه

زیر نام فارسی/انگلیسی، یک ردیف کوچک شامل پنج ستاره، میانگین و تعداد دیدگاه، کنار کد محصول و پیش از انتخاب تنوع است؛ لینک آن به `#reviews` می‌رود. همان summary پاسخ نظرات مصرف می‌شود و درخواست تکراری برای هدر نداریم. هویت محصول در state نگه داشته می‌شود تا میانگین محصول قبلی نمایش داده نشود. صفر/خطای اولیه عدد جعلی ندارد؛ خطای refresh با هشدار و retry همراه است.

هر ستاره یک SVG با گوشه نرم است؛ پر طلایی و خالی خاکستری روشن، با پرشدن جزئی پیوسته برای میانگین اعشاری. فرم دارای پنج radio بومی۱..۵ با ستاره، بدون باکس‌های جدا، بازخورد hover و انتخاب با صفحه‌کلید و focus قابل مشاهده است. برچسب خوانای «امتیاز ... از۵» و تعداد آرا مستقل از رنگ وجود دارد. پیشرفت بارگذاری روی فضای ثابت و احترام به reduced-motion است؛ موبایل بدون سرریز افقی بررسی شده است.
